# 종성이 자동차 테스트 게임 (Jongsung's Car Test Game)

Godot Engine 4.6.3 기반의 2D 탑다운 세로 스크롤 아케이드 회피 레이싱 게임입니다.

## 🎮 주요 게임 특징
- **세로형 픽셀 퍼펙트 해상도 (`540x960`)**
- **에너지 쉴드 자가 회복 시스템 (Shield Recharge System)**
- **아슬아슬한 근접 회피 스코어링 (Near-Miss System)**
- **고정식 레벨 설계와 3개 난이도 스테이지 (Deterministic Spawner)**
- **완전 절차적 2D 드로잉 (Procedural Vector Drawing)**

자세한 기획 및 디버깅 역사 이력은 [AGENTS.md](AGENTS.md)를 참조하세요!
